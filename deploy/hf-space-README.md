# StoryForge AI

Free, local-first story-to-video creator. This Space runs the full Mode B pipeline
(original script → offline Piper narration → FFmpeg-rendered MP4 with captions,
transitions and music) on free CPU hosting.

- First load after inactivity can take 1–2 minutes while the Space wakes up.
- Free-tier storage is ephemeral: download every MP4 you want to keep.
- Mode A text-to-video adapters are included but need a GPU model to be connected.
